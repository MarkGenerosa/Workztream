The toolkit

Every tab, in the order a technician actually works.

Workztream follows one routine: secure the system, clean it, repair it, then confirm it's healthy. Each tab picks up exactly where the last one left off — and this list has grown every month since the first release, not a fixed set decided on day one.

01

Prep & Safety

Restore point, software inventory, health score, and a one-click list of what's actually wrong.

02

Core Cleanup

SFC scan, Temp folders, Disk Cleanup, Storage Sense, drive optimization, Store cache reset - all quarantined, not deleted outright.

03

System Repair

DISM RestoreHealth, component store trim, forced Group Policy update.

04

Diagnostics & Health

Battery report, Chkdsk (read-only or fix-at-restart), memory diagnostic, SMART status.

05

Network

DNS/IP/ARP refresh, deeper Winsock resets, saved Wi-Fi password recovery, a speed test, and a scan of what's on your local network.

06

Updates & Apps

07

What's new

Grown well past a basic repair tool.

Three additions that turn Workztream from a fix-it kit into something you'd actually trust with the messier parts of the job.

NEW

A Health Score, not a vague verdict

A 0–100 score built from disk space, memory pressure, restore-point age, startup load, and Defender status — deterministic rules you can see, not an unexplained "AI" opinion. Click any flagged issue to jump straight to the tab that fixes it.

NEW

Cleanup you can undo

Temp file cleanup moves files to quarantine instead of deleting them outright. Restore a batch, or let it auto-purge after 7 days — a bad cleanup is never permanent by accident.

NEW

Debloating, without the guesswork

A curated list of commonly-unwanted pre-installed apps, each tagged Safe or Caution with a real explanation — not a blanket "select all" list. Paired with fully reversible privacy and telemetry toggles.

How it works

Three steps, start to finish.

1

Download the installer

Grab WorkztreamSetup.exe — no signup, just a standard Windows installer.

2

Install and launch

Run the installer and open Workztream. It prompts for the Administrator (UAC) elevation it needs on first launch.

WorkztreamSetup.exe → Install → Launch
3

Pick a tab, or run the sequence

Work through a tab by hand, or hit "Run Recommended Sequence" for the safe, automatable core routine.

Built solo. Kept free.
